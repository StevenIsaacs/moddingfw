# ModdingFW

A framework for developing and modifying devices. This includes not only the
firmware but the devices in which the firmware runs as well as devices the
firmware controls.

NOTE: ModdingFW is not a build system. Instead, ModdingFW is an integration tool designed
to integrate a variety of build systems and tool chains used to build both
software and hardware components.

ModdingFW also supports developing and modifying a means of deploying, monitoring,
and controlling these devices remotely in keeping with the Internet of Things
concept.

Secure remote access is provided using ModdingFW-proxy running on platforms provided
by hosting companies such as Hostwinds, Godaddy, and Midphase to name just a
few. ModdingFW provides mechanisms for managing the keys needed as well as
establishing tunnels for communicating with individual devices.
